# Good to know: To switch beween python tutorials, click on the drop down list in the top left corner of this page (on the left of branch), then choose your Tutotrial release.

## This Selected Pyton Tutorial Release Concerns: `Python Data Types and Variables declaration`

### How to download an run the project

1. **In the top right corner of this page: click on the `<> code` drop down list then choose `Download ZIP`, this will download the selected tutorial relase as a zipped folder** 
2. **In your downloads folder, right click on the zipped folder then extract it**
3. **Open VScode then go to `File->open folder`, select the exracted folder**
3. **Open `main.py` file, then click on run button in the top right corner of VScode**
