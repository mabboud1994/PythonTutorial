### How to download an run the project

1. In the top right corner of this page: click on the `<> code` drop down list then choose `Download ZIP`, this will download the selected tutorial relase as a zipped folder, you can alternatively download it from relases: [releases](https://github.com/mabboud1994/PythonTutorial/releases)
2. In your downloads folder, right click on the zipped folder then extract it
3. Open VScode then go to `File->open folder`, select the exracted folder
3. Open `main.py` file, then click on run button in the top right corner of VScode
